# CS 5100 — Foundations of Artificial Intelligence

**Northeastern University | Fall 2026**

This public repository documents my learning and completed programming assignments for CS 5100, Foundations of Artificial Intelligence.

> **Academic integrity:** The assignments use the UC Berkeley Pacman AI teaching projects, whose licensing notices say not to distribute or publish solutions. Accordingly, this public repository contains **descriptions only**, not assignment solution code or original submissions.

## Coursework overview

| Assignment | Topic | What I practiced |
|---|---|---|
| PA1 | Search | Graph search, uninformed and informed search, heuristics and Pacman search problems |
| PA2 | Multi-Agent Search | Reflex agents, minimax, alpha-beta pruning, expectimax and state evaluation |
| PA3 | Reinforcement Learning | Value iteration, Q-learning, approximate Q-learning and parameter analysis |
| PA4 | Upcoming | Will be documented after completion |

Read the individual non-solution summaries in the `assignments/` directory.
