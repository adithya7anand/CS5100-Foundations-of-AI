# PA1 — Search

**CS 5100 | Foundations of Artificial Intelligence | Fall 2026**

This assignment involved the Pacman search framework and implementing algorithms used to find paths through search problems.

## Topics

- Representing search problems with states, actions, successors and goal tests
- Uninformed search: depth-first, breadth-first and uniform-cost approaches
- Informed search with heuristics, including A*
- Applying algorithms to Pacman search agents and grid environments
